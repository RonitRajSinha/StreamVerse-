# 🎬 StreamVerse

**Discover movies. Explore streaming platforms. Find your next watch.**

StreamVerse is a movie discovery website that helps users explore movies, view posters, search titles, and check streaming availability across supported platforms.

🌐 **Live Demo:** [streamverse-india.vercel.app](https://streamverse-india.vercel.app/)

## ✨ Features

- 🔎 **Movie Search** — Find movies by title.
- 🎞️ **Movie Discovery** — Explore movie posters and details.
- 📺 **Streaming Availability** — Check where movies are available to watch.
- 🎯 **Platform Filters** — Filter movies by streaming platform.
- ❤️ **My List** — Save movies to your personal watchlist.
- 📱 **Responsive UI** — Enjoy a cinematic browsing experience.

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Vite
- TMDB API

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/RonitRajSinha/StreamVerse-.git
   ```

2. Navigate to the project folder:

   ```bash
   cd StreamVerse-
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

## 🔑 API Configuration

StreamVerse uses the TMDB API to retrieve movie information and posters.

Configure the required `TMDB_READ_ACCESS_TOKEN` environment variable in your deployment settings. Keep your API token private and never commit secrets to GitHub.
